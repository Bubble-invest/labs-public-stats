# labs-public-stats

One file, `labs-token-headline.json`, read by the token counter on bubbleinvest.org (Labo).

It holds only headline totals (this month, this year, all time, and their update time), published once a day from Bubble Invest's private token ledger. No per-agent, per-project or per-day data is ever published here.

Decision: Joris, 2026-10-12 (the ledger stays private; the site reads a headline-only public file).
